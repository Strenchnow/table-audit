# Vision & Scope — TableAudit (Local Data Quality Profiler)

## 1. Постановка задачи и проблематика

Системные и бизнес-аналитики, инженеры данных и разработчики регулярно сталкиваются с необходимостью анализа «сырых» табличных выгрузок из legacy-ERP, CRM-систем, бухгалтерских отчетов и партнерских интеграций (`.csv`, `.xlsx`, `.xls`, `.json`). На практике перед загрузкой этих данных в реляционную БД или хранилище возникает ряд типовых проблем:

1. **Проблемы совместимости форматов и кодировок:** файлы из корпоративных систем Windows часто выгружаются в кодировке `Windows-1251` и с разделителем `;`, что приводит к «кракозябрам» или смещению колонок при наивном импорте.
2. **Скрытые дефекты данных:** полные дубликаты строк, неявные маркеры пропусков (`N/A`, `-`, пустые строки), смешанные форматы дат (`2025-04-12` и `12.04.2025`), невалидные календарные даты (`2025-02-30`), разнобой в написании телефонов, числа в текстовом виде (`15 400 ₽`), лишние/невидимые пробелы (`\u00A0`, `\u200B`) и статистические выбросы.
3. **Конфиденциальность данных:** отправка клиентских и финансовых выгрузок в облачные SaaS-профайлеры запрещена требованиями информационной безопасности (ФЗ-152, внутренний комплаенс).
4. **Трудоемкость ручной сверки и проектирования DDL:** сравнение двух версий выгрузок и ручное составление `CREATE TABLE` с проверкой `NOT NULL` и ограничений `UNIQUE` занимают часы в Excel/скриптах.

**TableAudit** решает эти задачи в виде 100% автономного офлайн десктопного приложения для Windows и macOS.

---

## 2. Целевые пользователи

| Роль | Основные сценарии использования |
| --- | --- |
| **Системный аналитик** | Экспресс-аудит входных файлов перед интеграцией, формирование спецификации целевой таблицы БД (`CREATE TABLE`), передача формализованного HTML/Markdown-отчета команде разработки. |
| **Data / ETL-инженер** | Диагностика причин падения пайплайнов загрузки (битые даты, дубликаты PK/UNIQUE, смешанные разделители дробей), безопасная первичная нормализация файлов. |
| **Бизнес-аналитик / QA** | Сверка двух выгрузок (до и после миграции, либо план/факт), визуальный поиск выбросов по методу IQR и контроль полноты заполнения. |

---

## 3. Цели продукта

- Обеспечить мгновенный аудит качества табличных файлов до **100 000 строк** без блокировки UI и без передачи данных по сети.
- Дать прозрачную, математически обоснованную оценку качества данных (**Data Quality Score 0–100%**).
- Предоставить сквозной цикл работы аналитика в одном окне: *Загрузка → Диагностика → Сверка → DDL-схема → Базовая очистка → Отчет*.

## 4. Границы MVP (Scope)

### Входит в MVP (In Scope)
- Полностью локальная работа (Electron + Worker Thread, без внешних API и телеметрии).
- Загрузка `.csv` / `.tsv`, `.xlsx` / `.xls` (с выбором листа), `.json` (массив объектов / плоская проекция вложенных структур), а также встроенный демо-датасет (~1 000 «грязных» заказов).
- Автоопределение кодировок (`UTF-8`, `Windows-1251`, `KOI8-R`, `UTF-16`) и CSV-разделителей (`,`, `;`, `\t`) с ручным переключением.
- Дашборд с интегральным DQ Score, KPI и переходами к проблемным строкам.
- Профилирование по столбцам: 9 семантических типов, статистики (`min/max/mean/median/IQR`), топ-5 значений, графики распределения, поиск 10 типов дефектов.
- Виртуализированная таблица-инспектор с фильтрами и тултипами ошибок ячеек.
- Сверка двух таблиц по ключу (Только в A, Только в B, Diff значений «было → стало»).
- Генератор SQL DDL (`PostgreSQL`, `SQLite`) с предупреждениями о рисках (`-- WARNING`).
- Безопасная очистка (дубликаты, пробелы, даты в ISO 8601, запятые в дробях) с предпросмотром изменений и экспортом в `.csv` / `.xlsx`, а также экспорт отчетов в автономный `.html` и `.md`.

### Не входит в MVP (Out of Scope)
- Прямое сетевое подключение к внешним СУБД (JDBC/ODBC) для выполнения миграций.
- Распределенная обработка файлов свыше 1 ГБ (Out-of-Core / DuckDB / Parquet).
- Редактирование отдельных ячеек вручную внутри инспектора (реализованы только массовые безопасные правила очистки с экспортом нового файла).
- Облачная синхронизация или многопользовательская совместная работа.
